# AGENTS.md

This document orients AI agents and developers working on this codebase.

## Project Overview

Marketing and lead-generation website for **Agarwal Speed Packers & Movers**, a household and corporate relocation
company operating out of Alwal, Secunderabad, serving Hyderabad and Pan-India. Built with TanStack Start and
deployed on Netlify.

### Tech Stack

| Layer         | Technology                                  |
| ------------- | -------------------------------------------- |
| Framework     | TanStack Start (file-based routing)          |
| Frontend      | React 19, TanStack Router v1                 |
| Build         | Vite 7                                       |
| Styling       | Tailwind CSS 4                               |
| Icons         | lucide-react (+ a custom WhatsApp glyph)     |
| Lead capture  | Netlify Forms                                |
| Language      | TypeScript 5.9 (strict mode)                 |
| Deployment    | Netlify                                      |

## Key Concepts

### File-Based Routing (TanStack Router)

Each file in `src/routes/` is a real, bookmarkable, server-rendered URL — there is no client-only SPA router state.
Add a page by creating `src/routes/<name>.tsx` with `createFileRoute('/<name>')(...)`. Per-route `head()` sets the
page title and meta description; `routeTree.gen.ts` is auto-generated by the TanStack router Vite plugin, do not
hand-edit it.

### Lead Capture (Netlify Forms)

`QuoteForm.tsx` posts to `/__forms.html` (not `/`) so the request reaches Netlify's form-processing middleware
instead of the SSR catch-all. `public/__forms.html` is a hidden, non-rendered HTML form that exists solely so
Netlify's build bot detects and registers the `quote-request` form and its fields — keep the two in sync if you add
or rename a field. Submissions (including the calculated estimate) appear in the Netlify dashboard under
**Forms**, independent of whether the visitor also follows through on WhatsApp.

### Content

All copy, service areas, services, FAQ, reviews, and gallery entries live in `src/data/company.ts`. Update the
business's phone number, address, or service list there — it is the only place those values are defined.

## Conventions

- Components: PascalCase, one component per file in `src/components/`
- Tailwind utility classes for styling; no CSS-in-JS
- TypeScript strict mode — avoid `any`, prefer typed props/interfaces
- Import paths use the `@/` alias for `src/*`

## Development Commands

```bash
npm run dev      # Start dev server (also: netlify dev --port 8889 for full Netlify emulation)
npm run build    # Production build
```

Netlify Forms only accept real submissions on a deploy — local `dev` will not show entries in the Netlify dashboard.
